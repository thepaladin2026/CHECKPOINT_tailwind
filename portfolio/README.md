# Jean Baptiste David N'Guessan — Tailwind Portfolio

This version is a Tailwind CSS implementation of the original portfolio.

## What was kept
- Original dark navy / orange visual identity
- Original profile image and dashboard video assets
- About, skills, projects, resume and contact sections
- Original professional positioning and content
- Responsive behavior and accessibility details

## Tailwind requirement
Tailwind CSS is loaded through the CDN and the page is styled directly with Tailwind utility classes in `index.html`.

## Run
Open `index.html` in a browser while connected to the internet (the Tailwind CDN and Google Fonts are external).
